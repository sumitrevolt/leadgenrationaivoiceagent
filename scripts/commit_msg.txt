fix(main): unversioned production image is a LOUD startup failure (ADR-097)

ROOT CAUSE of ~1,170 Sentry events. docker-compose.vps.yml tags
${APP_VERSION:-latest}, so a deploy that forgets APP_VERSION silently leaves prod
on an UNVERSIONED :latest image. /health then reports version "latest" and nobody
can tell what code is running. That is not cosmetic: production sat on stale code
while fixes were merged to main and never reached it.

What the stale image was actually costing (all live-verified):
  - /api/voice/niches, a PAID Voice Agent revenue route (Rs 4,999-19,999/mo),
    returned 500 for SIX DAYS -- PYTHON-G 379 + PYTHON-H 224 + PYTHON-M 179 +
    PYTHON-R 90 = 872 events -- even though the real cause (a retired
    lead_topup_price import) was ALREADY fixed in main.
    The '_IncludedRouter' object has no attribute 'path' title was the exception
    handler's own secondary crash masking the real ImportError.
  - ~277 app.middleware._record event-loop errors (PYTHON-K/N/P).
  - qdrant "fastembed model not ready within 90s" at fail_rate 1.0.

Rebuilding with a real SHA (91e7d37 -> 1feed53) took EVERY one of those to zero
within 30 minutes: /api/voice/niches -> HTTP 200 with real band pricing, and
"fastembed model loaded: paraphrase-multilingual-MiniLM-L12-v2 (dim=384)".

The gap: prod_check and CI validate the SOURCE; nothing validated that the
RUNNING IMAGE was built from that source. Silent drift lived in that gap.

- add pure, testable is_unversioned_production_image(app_version, app_env).
- lifespan guard (production only): logs ERROR + pages ntfy high-priority when
  APP_VERSION is unset/latest/dev/1.0.0. Mirrors the existing "CRITICAL routes
  missing after startup" sweep directly above it. INERT outside production.
- settings.app_env is the real field; there is NO settings.environment (a getattr
  on the wrong name would have silently no-opped the guard).

Rejected: compose ${APP_VERSION:?err}, which would hard-break unrelated
`docker compose up <service>` ops across ~5 services for the same detection.

Tests: 55 passed (new test_image_provenance_guard + voice_product_contract +
customer_delivery + whatsapp_selfhost). prod_check ALL CHECKS PASSED (1102
routes). check_secrets clean.
