================================================================================
THE 6-STEP HEALTH CHECK (audit-automation)
================================================================================

Run: python scripts/automation_health_audit.py --daily-check

Checks:
  1. Loop Alive? (Heartbeat age)
     ✅ <10m:   Healthy
     🟡 10-30m: Slow (check LLM providers)
     🔴 >30m:   Stuck (restart service immediately)

  2. Budget (Daily spend vs. cap)
     ✅ <40%:    Normal velocity
     🟡 40-80%:  Approaching limit
     🔴 >80%:    Budget exhausted, loop paused

  3. Approvals (If enabled)
     ✅ ≤2 pending:  Flowing smoothly
     🟡 3-5 pending: Backlog building
     🔴 >5 pending:  Blocked

  4. Anomalies (Task success rates + errors)
     ✅ All >70%, DLQ clean
     🟡 1-2 low actions
     🔴 Multiple failures or DLQ >10

  5. Next Action (What's running + what's queued)
     ✅ Current running, queue <3
     🟡 Queue 3-5 items
     🔴 Task stuck >240s or queue >10

  6. Compliance (DLT, opt-out, retention, approvals)
     ✅ DLT enabled, opt-outs enforced, retention active
     🟡 Gaps pending resolution
     🔴 No DLT, ignoring opt-outs (illegal risk)

Output:
  Human-readable console with 6 sections + verdict
  OR JSON for dashboard integration

THE 6 STEPS TO ADD NEW ACTION (teach-agent-loop)
================================================================================

Time: 15 min (fastest path)

1. Define (1 min)
   - Name: sms_campaign_draft
   - Cost: Light (free-LLM)
   - Risk: Draft-only (humans send)

2. Write Code (5 min)
   - New file: app/agents/sms_agent.py
   - Async function returning {ok: bool, detail: str, output: ...}

3. Register in self_improve.py (3 min)
   - Add to ACTIONS dict
   - Add execution in _execute()
   - Add to _STAGE_ACTIONS

4. Register in skill_library (1 min)
   - Auto-learns on first run (no manual action)

5. Test (3 min)
   - Happy path ✓
   - Empty data ✓
   - LLM down ✓
   - Timeout ✓
   - Concurrent ✓

6. Enable & Monitor (2 min)
   - No special env flag (draft-only)
   - Monitor via automation_health_audit.py --weekly-audit

================================================================================
THE 6 STEPS TO ADD NEW AGENT (teach-agent-loop)
================================================================================

Time: 90 min (longer path)

1. Define (5 min)
   - Name: Priya
   - Role: Competitive Research
   - Responsibilities: 2-5 tasks

2. Create Code (20 min)
   - New file: app/agents/priya.py
   - Functions: research_competitors(), analyze_pricing(), etc.

3. Add to Team Roster (5 min)
   - Edit: app/platform/team.py
   - Add to STAFF dict with capabilities

4. Wire into Coordinator (10 min)
   - Edit: app/agents/coordinator.py
   - Add to AGENT_HANDLERS

5. Add to Self-Improve (20 min)
   - New actions in self_improve.py
   - Add to ACTIONS, _execute(), _STAGE_ACTIONS

6. Test & Document (30 min)
   - Coordinator test
   - Self-improve test
   - Dashboard verify

KEY INSIGHTS
================================================================================

Philosophy:
  1. Automation loops are black boxes. Transparency > complexity.
  2. Extension should be safe & guided. Checklists > hope.
  3. Testing is non-negotiable. 5 scenarios, not "works for me".

Design Principles:
  - No code changes to existing systems (skills are pure documentation + CLI)
  - Gradual approach: daily standup → weekly review → monthly strategy
  - Risk assessment up-front (safety gates before enabling)
  - Defensive programming (fail-open, graceful degradation)
