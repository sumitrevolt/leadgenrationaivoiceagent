## Approach (minimal additive)

1. New durable control module + store (Postgres + JSONL fallback) for per-agent execution controls.
2. Enforce at existing choke-points (`scheduler_dispatch_allowed`, `OwnerSchedulerGuardedTask`/`run_staff_job`, `_run_job`, `run_member`).
3. Read-only `workflow_registry` / Isha detail aggregating existing sources — **no second scheduler**.
4. Owner OS OmniRoute matrix + sanitized health test over approved task keys only.
5. Extend Training Mode + thin Isha control UI (not broad redesign).

## Control semantics (Isha)

| Control | Behavior |
|---------|----------|
| Pause Manual Runs | blocks `run_member` / Owner OS manual only |
| Pause Scheduled Dispatch | blocks new enqueue for Isha-owned jobs |
| Stop New Task Claims | worker must not start new Isha job bodies |
| Drain | scheduled pause + stop claims; running may finish; `drained` when queued+running=0 |
| Cancel Queued Task | revoke only if not started; audit; else honest refuse |
| Request Cancel Running | cooperative Redis flag; unsupported if job never checks |
| Resume / Restore Default | clears agent controls; no catch-up flood |

Precedence: global kill → drain → stop_claims → scheduled_pause → manual_pause.
