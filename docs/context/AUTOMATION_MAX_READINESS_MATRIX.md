## Label vocabulary (as agreed with user)

- **PRODUCTION-PROVEN** — code + tests + user-declared LIVE in prod (from CLAUDE.md hot facts / this task's context header). This file cannot confirm prod on its own; the label is inherited from that declared context and is falsifiable by `/health`.
- **TEST-PROVEN** — pytest module directly exercises the capability (`tests/test_*.py`).
- **CODE-PRESENT** — real files exist and the capability is import-safe, but no user-declared LIVE or dedicated test row.
- **CONFIGURED-INERT** — code exists, flags are wired, defaults are OFF and the runtime path is a graceful no-op until an operator flips the flag.
- **OWNER-ACTION-REQUIRED** — the code side is done; the last mile is a human decision (key rotation, DLT paperwork, external approval, canary green-light).
- **HARD-OFF** — permanently disabled by policy (compliance / ban-safety); not eligible for enablement without a documented policy reversal.
