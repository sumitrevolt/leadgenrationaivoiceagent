## Gaps → actions (skill checklist se, priority order)

1. **Cold-email me magnet = FIRST-LINE offer** (0-reply root ka content-lever): pitch nahi, value do — "aapke <business> ka Google score X/100 nikala, report yahan" (personalized audit link/utm). Generic intro-mail delete. → `cold-email-craft` ke saath.
2. **Result/thank-you page = next-step CTA** (skill: "don't waste the thank-you page"): score dikhane ke BAAD 1-click next step — WhatsApp chat / `/pricing` / "5 din me fix karwa lo". VERIFY: abhi result-page pe kya hai (`frontend/audit.html`) — agar dead-end hai to yeh #1 conversion leak hai.
3. **Content upgrade on programmatic SEO pages**: har niche/blog page pe niche-specific CTA ("<niche> ke liye apna score nikalo" → `/audit?niche=X&utm_source=seo`). Skill: content upgrades = 2–5x generic CTA. Blog/SEO engine template me ek block = saare pages pe leverage (C1.4).
4. **Capture = minimum fields**: phone(WhatsApp) ya email — ek primary. Har extra field = −5–10% conversion. VERIFY current form fields.
5. **Per-magnet P&L metric** (C1.3): magnet_visit → capture → inquiry → paid, per source (utm). Vanity (visits) nahi — paying-customer distance. Existing analytics/events me utm-source slice.
6. **A/B pehla test**: `/audit` headline — benefit ("2 minute me Google score") vs loss-aversion ("Aapke customers aapko Google pe kyun nahi dhoondh paate"). Baseline conv-rate note karo pehle (cold-traffic benchmark 5–15%).
