# GTM Pilot Playbook — pehle 5 paying customers (founder-led)

> Council verdict 2026-06-25: platform feature-complete + live. Asli lever = **founder-led sales**, code nahi. Goal = **3-5 design-partner logos + proof** (screenshots/testimonials), fir paid scale. Ye doc wahi action hai. Automation activity banata hai; **deal insaan close karta**.

## The Offer (proof-first, friction-zero)
> "Pehla mahina **₹0** — main aapka marketing khud chalaa ke result dikhaata hoon (Google pe dikhna, leads, content). Pasand aaye to **₹1,199/mo**, nahi to band. Koi contract nahi."

- ₹0 month-1 = trust-barrier todta (zero case-study problem ka fix).
- Sirf **Starter ₹1,199** offer karo pilot me — sasta haan bolwana easy.
- Maqsad paisa NAHI, **proof**: 1 result-screenshot + 1 testimonial + 1 logo per pilot.

## Target — ONE niche × ONE city (focus = leverage)
Ek hi niche + ek hi city pakdo (referrals + "main aapke ilaake me X businesses ke saath kaam kar raha" credibility deta).
- **Niche pick:** jo tum samajhte ho + jinke paas paisa + jinko leads chahiye → solar / real-estate broker / coaching / gym / clinic / interior.
- **City pick:** jahan tum **call/visit** kar sako (founder presence = trust).
- **Worked example:** *"Real-estate brokers — Pune"* ya *"Solar dealers — Nagpur"*. Ek chuno, is hafte sirf wahi.

## Daily motion (is hafte)
1. **20-30 reach-outs/din** — Google Maps se us niche+city ke businesses, WhatsApp/call. (Prospector already ye list deta — `/app/outreach`.)
2. **Hot reply aaye → 1 ghante ke andar khud call/WhatsApp.** Draft close nahi karta, insaan karta. (reply-triage flag deta → tum jump karo.)
3. Roz shaam: kitne reach kiye / kitne reply / kitne pilot haan — track karo (3-5 haan = target).

## Outreach script (Hinglish — copy/paste)
**WhatsApp/Call opener:**
> "Namaste [Naam] ji, main [Tumhara naam] — LeadsGenAI se. Main [city] ke [niche] businesses ka online marketing AI se chalaata hoon — Google pe dikhna, daily content, leads. Aapke liye **pehla mahina free** chala ke dikhaun? Pasand aaye to ₹1,199/mo, warna koi baat nahi."

**Agar "kya hota hai usme":**
> "Main aapke business ka ek mini-site + Google profile optimize, roz social content, aur jo log inquiry karein unko AI se follow-up. Aap bas leads dekho. Setup main karta hoon, aaj hi shuru."

**Follow-up (1 din baad, no reply):**
> "[Naam] ji, bas free pilot ka pooch raha tha — 5 min me setup ho jaata hai, koi paisa nahi pehle mahine. Try karein?"

## Pilot delivery (haan ke baad — same day)
1. `/app/clients` me add → `/b/{slug}` mini-site auto-banta → website→KB seed + first content pack (AUTO_ONBOARD).
2. Week-1 me **ek visible result** banao (Google profile live / 1 lead / content calendar) → screenshot.
3. Result dikha ke: "Pasand aaya? ₹1,199/mo se continue karein" → **UPI** (customer page pe ab self-serve 'Maine Pay Kiya' submit live hai → tum minutes me activate).

## Proof loop (sabse zaroori)
Har pilot se nikaalo: **logo + 1-line testimonial + 1 result-screenshot** → landing page pe daalo. 3 proof = next sales 5× easy. (Face + 3 testimonials site pe = #1 conversion lever — agla site-change yahi.)

## STOP (council)
- Naye features / flags / repo-mining — band, jab tak paying customer demand na kare.
- Voice cold-calling product — DLT tak ₹0, abhi mat becho.
- Cold-email volume mat badhao bina proof ke (domain reputation jalti hai).
