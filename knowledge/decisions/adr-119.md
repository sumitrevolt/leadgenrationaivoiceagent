# ADR-119 — Hybrid Agentic RAG + OKF

**Verdict:** Use both. OKF is the curated/source layer. Qdrant Hybrid Agentic RAG is retrieval. Postgres is live truth. Graphify is relationship context.

Production must not become OKF-only while OKF v0.1 is an early draft.
